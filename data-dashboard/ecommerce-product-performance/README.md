# 电商商品表现看板示例数据

这是一组**虚构但合理**的电商商品运营数据，用于体验卡「数据分析与决策：把商品数据变成运营看板」场景。数据不包含真实用户、真实订单或真实商家信息。

## 文件说明

- `data/products.csv`：商品主数据，包含商品 ID、名称、品类、价格、评分和上架日期。
- `data/daily_sales.csv`：最近 14 天商品表现，包含曝光、点击、订单、销量、销售额和退款件数。
- `data/inventory.csv`：库存数据，包含当前库存、安全库存和供应商补货周期。

## 可分析问题

这组数据适合让 Agent 自动计算并可视化：

- 销售额、销量、转化率、客单价、退货率、库存风险；
- 最近 7 天趋势与环比变化；
- 商品排行榜与品类表现；
- 值得重点推广的商品；
- 需要补货的商品；
- 曝光不足但转化率高的商品；
- 退货率偏高或销量下滑的观察商品。

## 建议 Prompt

```text
请从公开数据仓库读取一份虚构电商商品数据，帮我生成一个商品表现看板，并发布成可访问链接。

看板需要展示销售额、销量、转化率、客单价、退货率、库存、商品排行榜、异常商品和最近 7 天趋势，并找出值得重点推广、需要补货、曝光不足和需要观察的商品。请做成适合运营每天查看的商品决策看板，而不是普通数据表。

数据仓库：https://github.com/Sumomo0222/agent-experience-scenario-assets.git
版本：ecommerce-product-dashboard-v1
数据目录：data-dashboard/ecommerce-product-performance/data/
```

## 字段口径

- 点击率 = clicks / impressions
- 下单转化率 = orders / clicks
- 件单价 = revenue / units_sold
- 退款率 = refunds / units_sold
- 库存风险 = 当前库存低于安全库存，或按近 7 天日均销量估算的可售天数小于供应商补货周期

## 说明

这组数据故意设置了若干可发现的业务信号，例如：爆款上升、库存风险、退货率偏高、曝光不足但转化较好、销量下滑等，便于验证 Agent 是否能从数据中提炼行动建议。
